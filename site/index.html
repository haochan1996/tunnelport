三个承诺

01 一条命令 安装即用，中继配置、token、端口映射全自动生成。
02 不用管端口和 IP 自动检测公网连通性、自动挑一个未被占用的端口、自动输出可复制的地址和二维码。
03 一眼看出哪一环 tp doctor 把本地 → 中继 → 鉴权 → 隧道 → 外部五段逐项判定，每项给一句人话和一个动作。

为什么需要它

四条现成的路，都不好用

Orca 手机端连桌面只有两条官方路径：境外 Relay 和同网络直连。你手里的 VPS 本来就能当入口，但要自己配 frp、处理防火墙、DDNS、断线重连 —— 绝大多数人卡在这一步，或者配完三天后坏了不知道怎么修。

01 官方 Relay 接入点在境外，大陆经常超时或 DNS 被污染。慢、常断、不可控。
02 手写 frp 配置 端口、token、TLS、自启、日志全要自己搞，一处漏了就整条链断。
03 ssh -R 临时隧道 断线不恢复，重启就没了，不适合"打开就自动连"的日常使用。
04 Tailscale 控制面在境外，4G 下经常退回境外 DERP，延迟不可预测。

核心功能

坏的时候，让它自己说出原因

五段链路，逐项判定。前一段失败，后面的段直接标记跳过 —— 不猜、不伪造通过。每一项只输出三件事：一句事实、一句人话、一个动作。

$ tp doctor A 本地服务 ✔ Orca 在 127.0.0.1:6768 B 中继可达 ✘ 连不上 1.2.3.4:30123 → 检查云厂商安全组 / 防火墙是否放行 TCP 30123 C 鉴权 – 跳过（B 失败） D 隧道 – 跳过 E 外部可达 ✔ 出口 1.2.3.4 与入口一致 结论：中继端口不通，最可能是安全组没放行。

外部那一环由手机判定：中继额外暴露一个只回状态的 /health，用 4G 打开就知道手机到底能不能连上。

验证记录 · 2026-11-08

测过的公开，没测过的不装

MVP 还没发布，但我们把每一次验证的结果写在这里。下面全部是真实测试，不是承诺；测不了的如实列出。

已验证

单机全链路隧道 serve 起中继 → connect 连入 → HTTP 请求穿透拿到真实响应。
跨机全链路隧道 一台机器 Docker 部署中继，另一台机器连入，穿透往返实测 RTT 3ms。
Docker 一键部署 TP_ROLE / TP_PORT 两个环境变量，容器启动即输出地址、token 和二维码。
外部可达自检 健康端点实测可用：手机浏览器打开 /health 即验最后一环，不需要任何后端。
五段诊断 A/B 段 本地端口探测与中继可达（含 RTT）实测准确，坏中继能定位到安全组。
优雅退出 SIGTERM / 容器停止后，tp 与隧道引擎同步退出——无孤儿进程、端口即释。NAS 上 restart=always 依赖这一点。
配对安全 状态目录零明文 token；错误 token 只说「重新复制」，不吐堆栈。
链路 TLS 加密 隧道已默认 TLS：证书自动生成，指纹随配对码携带，不匹配即中止并提示中间人。
端到端加密模式 手机到桌面全程 TLS，中继只见密文。已在内网实测穿透；待手机真机验证 https:// 支持。

实测发现并已修复

隧道引擎配置格式 rathole v0.5.0 的配置格式与主分支文档不一致 —— 已按 tag 源码对齐，并固定版本。
安全软件拦截 实测国产杀软会静默删除隧道引擎文件 —— tp 已能识别并给出白名单指引。
引擎报错不可见 子进程错误曾被吞掉 —— 现已落盘成日志，坏的时候有据可查。
代理网络的入口检测 实测软路由/代理环境下，出口 IP 自动检测返回的是代理地址 —— 已支持显式指定入口地址。

常见问题

先把边界说清楚

需要自己有 VPS 吗？ 需要。而且这个 VPS 必须能放行入站端口 —— 云厂商安全组这一关要你自己过，tp doctor 会明确告诉你去哪个端口上放行。
家里 NAS 没有公网 IP，能当入口吗？ 不能。没有公网 IP 的机器只能当客户端。tp serve 会在启动时先判定 CGNAT 并直接告诉你"无法被外部连接"，不会让你白等。
我的数据会经过你们的服务器吗？ 不会经过我们的服务器——我们根本没有服务器。中继进程跑在你自己的 VPS 上。加密现状：隧道链路已默认 TLS 加密（自签证书 + 指纹防中间人），并提供端到端模式——手机到桌面全程加密，中继只见密文。即便如此，我们依然不做任何记录与落盘。
能不能用来翻墙？ 不能，也不做。产品只转发你自己的设备到你自有机器的 TCP 端口，没有多跳、没有出口 NAT、不服务跨境路径。这类用途请另找工具，我们不提供也不支持。
为什么不用 Tailscale 或 frp 自己配？ 能自己配得很稳的人确实不需要这个产品。它卖的不是"能连"，是"三分钟配好"和"坏了能自己诊断" —— 如果你的时间成本低于这个价，用自己的方案是对的。
VPS 上端口被别的程序占了怎么办？防火墙要放行几个？ 什么都不用做。tp 默认自动找一段连续的三个端口（控制 / Orca / 健康各占一个）， 防火墙放行 30123-30125 这样一段范围即可；被占用时整段顺延并明确告诉你手机该填哪个地址，配对码里自动携带。 想固定端口段就用 --port-base；段被占用会直接报错提醒你去检查防火墙，不会擅自换到你没放行的端口。
现在能下载吗？ 还不能。MVP 正在开发，规格已定稿并公开在仓库里。点 GitHub 上的 Watch 可以在第一个 tag 发布时收到通知。
