# tunnelport

> 一条命令，把已有的 VPS/NAS 变成 Orca 手机端的稳定入口。不用配 frp，不用管端口和 IP，连不上时能一眼看出是哪一环。

**状态：MVP 开发中。** 规格已定稿，暂无可用二进制。

> 产品需求书、定价与风险分析等属于内部文档，不在本公开仓库内。

---

## 它解决什么

Orca 手机端连桌面有两条路，都不好用：

- **官方 Relay** —— 接入点在境外，大陆经常超时或 DNS 被污染
- **直连** —— 要求同一网络路径，出门就断

你手里的 VPS/NAS 本来就能当入口，但要自己配 frp / `ssh -R`，还得处理端口、防火墙、DDNS、断线重连。绝大多数人卡在这一步，或者配完三天后坏了不知道怎么修。

tunnelport 只做一件事：**把这台机器变成入口的过程，从「看教程 1 小时」压缩到「一条命令 3 分钟」，并且坏的时候能自己说出原因。**

## 三个承诺

| 承诺 | 对应能力 |
|---|---|
| 一条命令 | 安装即用，配置全自动生成 |
| 不用管端口和 IP | 自动选端口、自动检测公网、自动出地址 |
| 一眼看出哪一环 | `tp doctor` 把五段链路逐项判定 |

## 命令

```sh
tp serve                    # 在 VPS 上起中继，输出 地址 / token / 二维码
tp connect --token <t>      # 在桌面机上连中继，映射本地 6768
tp doctor                   # 五段诊断：本地 → 中继 → 鉴权 → 隧道 → 外部
tp status                   # 地址、状态、RTT
```

## 明确不做

- **不用于翻墙**。只服务国内网络路径下的自有设备互联，拒绝任何穿透用途
- 不运营中继节点（中继跑在**你自己的**机器上）
- 不做账号体系、控制面、Web 面板、计费系统
- 不做 P2P 打洞（v2 再考虑）
